# B-guru Filter

bsm.backspace.fm (B-guru) で特定の単語を含むポストをタイムラインから非表示にする Google Chrome 拡張機能です。

## 特徴
- **リアルタイム監視**: タイムラインのスクロールや新規投稿の自動読み込み（MutationObserver）に対応。
- **完全非表示**: 投稿のルートコンテナ（`[data-post-id]`）を丸ごと非表示にするため、余白やボタン類も残りません。
- **簡単ワード管理**: 拡張機能のポップアップUIからいつでもNGワードの追加・一覧・削除が可能。
- **同期保存**: 設定したNGワードは `chrome.storage.sync` に保存され、ブラウザ間で同期されます。

## インストール方法
1. このリポジトリをダウンロード（または `git clone`）します。
2. Google Chrome で `chrome://extensions` を開きます。
3. 右上の「デベロッパー モード」を **ON** にします。
4. 左上の「パッケージ化されていない拡張機能を読み込む」をクリックし、このフォルダを選択します。
5. https://bsm.backspace.fm/ を開いてお使いいただけます。
